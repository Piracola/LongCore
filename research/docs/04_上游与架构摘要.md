# 04 · 上游与架构摘要

> 完整审计见 `archive/04_上游审计_全文.md`。本页只保留仍指导开发的事实。  
> 审计对象：GaoXanSheng/JiaolongControl `windows/X86-64` · 本地 `JiaoLongControl/`

## 架构

```
Client/   Vue 3.5 + TS + Vite + Arco + ECharts + Pinia + Tailwind 4
   ↕ WebView2 COM Bridge
Server/   .NET 8 WPF 宿主
   Bridge.cs → Controllers
   MethodServices.cs   ← WMI 透传（唯一标准入口）
   Blding64.cs         ← EC 直读（JiaoLongDriver64.sys）
   PawnIO.cs           ← SMU（RyzenSMU / AMDFamily17 / Nvidia.bin）
```

配置：YAML `JiaoLongConfig`，约 5s 差异落盘。

## 三条硬件通道

| 通道 | 能力 | 风险 |
|---|---|---|
| WMI `MICommonInterface` | 模式/风扇读/键盘灯/功耗/锁（命令 8–23） | 低–中，重启多可恢复 |
| EC 直写（端口 0x4E/0x4F） | 风扇手动转速与曲线 | **高**，见 08 |
| PawnIO / SMU | Curve Optimizer / PBO / TDC·EDC | 中，电气敏感 |

### EC 关键寄存器（最稀缺知识）

| 地址 | 用途 |
|---|---|
| `0xC834/0xC835`、`0xC836/0xC837` | CPU/GPU 风扇 RPM 读 |
| `0xC83C/0xC83D` | 手动转速写 |
| `0xB20` | 手动掩码：CPU `|=0x02`，GPU `|=0x08`；自动 `=0x00` |
| `0x2000` | EC ID，`==0x55` 时 `0x1060 |= 0x80` |
| `0xC411` | EC 版本 |

## 与上游差异 / 缺口（LongCore 已补）

| 项 | 上游 | LongCore |
|---|---|---|
| WMI 响应校验 | 无 | 有回显校验 + 重试 |
| 热键 HID_EVENT20 | 无 | 已实现（性能模式循环 + OSD） |
| 性能模式 | 3 档 | + CustomMode 本地逻辑态 |
| EC 写护栏 | 无 | 地址白名单 + 节流 + 崩溃恢复（见 08） |
| UI | 动漫横幅/视频背景 | M1 去毒后 → 09 硬件仪表重设计 |

## 运行注意

- 加载 `JiaoLongDriver64.sys` 需处理内存完整性拦截  
- 勿与官方控制中心同时抢风扇控制权  
- SMU 写从保守值起步（如 CO 全核 -10）
