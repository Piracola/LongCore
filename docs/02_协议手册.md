# 蛟龙 16 Pro (MRID6) WMI 硬件协议手册

> 本文档基于两部分证据：反编译源码 `decompiled/main.cs` + 本机实测（BIOS `MRID6_23_V33`，2026-09-06）。
> 所有只读命令已实测验证；**写命令仅给出协议，未实测**。

## 1. 通道总览

```
┌─────────────────────┐
│  控制中心 / 第三方工具  │
└──────────┬──────────┘
           │ 三条独立通道
   ┌───────┼──────────────┐
   ▼       ▼              ▼
 WMI 通道  KaronOC.dll   WMI 事件通道
 (EC/ACPI) (NVAPI)       (热键)
```

| 通道 | WMI 对象 | 能力 |
|---|---|---|
| 1. 方法调用 | `root\WMI:MICommonInterface`，实例 `ACPI\PNP0C14\MIFS_0` | 模式/风扇/键盘灯/功耗/锁 |
| 2. 原生库 | `KaronOC.dll`（P/Invoke，NVAPI） | GPU 核心时钟/显存时钟偏移 |
| 3. 事件订阅 | `root\WMI:HID_EVENT20` | Fn 热键推送 |

## 2. WMI 方法签名

```
类:     MICommonInterface        GUID {b60bfb48-3e5b-49e4-a0e9-8cffe1b3434b}
实例:   ACPI\PNP0C14\MIFS_0
方法:   MiInterface
  IN    InData    UInt8Array  (必须恰好 32 字节)
  OUT   OutData   UInt8Array
  OUT   Reserved  UInt16      (实测恒为 0)
返回值  Boolean
```

## 3. InData 请求包布局（32 字节）

| 偏移 | 含义 | 取值 |
|---|---|---|
| `[0]` | 固定 | 0x00 |
| `[1]` | 方法类型 | **0xFA (250) = 读** / **0xFB (251) = 写** |
| `[2]` | 固定 | 0x00 |
| `[3]` | 命令码 | 见 §5 命令表 |
| `[4..]` | 参数 | 写命令时填入，读命令留 0 |
| `[8..31]` | 固定 | 0x00 |

反编译证据（`WMIMethodServices._MakeMethodPrams`）：
```csharp
byte[] array = new byte[32];
array[1] = (byte)wMIMethodType;   // Get=250, Set=251
array[3] = (byte)wMIMethodName;   // 命令码
// SetValue 重载从 array[4] 起追加参数
```

## 4. OutData 响应包布局

| 偏移 | 含义 | 实测 |
|---|---|---|
| `[0..1]` | 响应头 | 恒为 `00 80` |
| `[2]` | 固定 | 0x00 |
| `[3]` | **命令码回显** | 与请求一致（校验用） |
| `[4]` | 数据字节 0 | 多数命令=主返回值 |
| `[5..7]` | 数据字节 1-3 | 风扇/RGB 色等用 |

**16 位读取约定**（反编译 `GetValue<T>`）：`value = (OutData[5] << 8) + OutData[4]`，即小端。

实测样例（读风扇，命令 13）：
```
请求: 00 FA 00 0D 00 00 ...
响应: 00 80 00 0D B7 0D 7F 0D ...
                     └─┬─┘ └─┬─┘
              CPU = 0x0DB7 = 3503 RPM
                         GPU = 0x0D7F = 3455 RPM
```

## 5. 命令表（反编译枚举 WMIMethodName）

| 码 | 名称 | 参数 / 返回 | 说明 |
|---|---|---|---|
| 8 | SystemPerMode | 返回 0=均衡 1=性能 2=静音 | 性能模式，写=切模式 |
| 9 | GPUMode | 返回 0=混合 1=独显直连 | **写后必须重启生效** |
| 10 | RGBKeyboardStatus | 0=关 1=开 | 键盘背光总开关 |
| 11 | FnLock | 0=关 1=开 | Fn 锁定 |
| 12 | TPLock | 0=关 1=开 | 触摸板锁定 |
| 13 | CPUGPUFanSpeed | 返回 2×u16（小端） | [4..5]=CPU RPM，[6..7]=GPU RPM |
| 14 | GPUFanSpeed_NotUse | — | 声明未使用 |
| 15 | Ambientlight | 0=关 1=开 | 氛围灯 |
| 16 | RGBKeyboardMode | 0=灭 1=自动循环 2=固定色 3=自定义 | 灯效模式 |
| 17 | RGBKeyboardColor | 写 3 字节 `[R,G,B]`；读 [4][5][6] | 固定模式下颜色 |
| 18 | RGBKeyboardBrightness | 0-10，128=自动 | 键盘亮度 |
| 19 | SystemAcType | 返回 1=TypeC 2=圆口 | 只读 |
| 20 | MaxFanSpeedSwitch | 0=关 1=开 | 强冷开关 |
| 21 | MaxFanSpeed | 实测 58 | 强冷相关（待定语义） |
| 22 | CPUThermometer | 返回当前 CPU 温度 | 实测 75（°C）|
| 23 | CPUPower | 见 §6 | CPU 功耗子系统 |

命令码 0-7 与 24-40 实测也能返回（回显命令码但数据全 0），判定为未实现/保留。

## 6. CPUPower (23) 子协议

`Set CPUPower` 的参数是 `[类型, 值]` 两字节（反编译 `Set_SPLSlider` 等）：

| 参数[4] | 含义 | 参数[5] | 范围（反编译得出） |
|---|---|---|---|
| 0 | 关闭自定义模式 | — | — |
| 1 | 打开自定义模式 | — | — |
| 2 | 设置 SPL | 功耗值 | 75–85 W（默认 82） |
| 3 | 设置 SPPT | 功耗值 | 105–120 W（默认 105） |
| 4 | 设置温度墙 | 温度值 | 反编译未见强制范围 |

`Get CPUPower`（只读）返回"当前处于哪个子状态"（枚举 `WMICPUPower`：0=Close 1=Open 2=SPL 3=SPPT 4=TempWall），本机实测返回 0。

## 7. 热键事件 HID_EVENT20

```
GUID {46c93e13-ee9b-4262-8488-563bca757fef}
订阅: SELECT * FROM HID_EVENT20
载荷: EventDetail: UInt8Array
  EventDetail[0] = 事件类型 (1=热键)
  EventDetail[1] = 事件名，见下表
  EventDetail[2] = 数值（如亮度档位）
```

事件名表（反编译枚举 `WMIEventName`）：

| 值 | 事件 | 值 | 事件 |
|---|---|---|---|
| 4 | 飞行模式键 | 15 | 性能模式切换 |
| 5 | 亮度调节 | 16/17 | FN_J / FN_F |
| 6 | 触摸板开关 | 18-22 | FN_0..FN_4 |
| 7 | Fn 状态 | 24 | FN_5 |
| 8 | 灯效模式键 | 25 | 屏幕刷新率 |
| 9 | CapsLock | 26 | CPU 风扇 |
| 10 | 氛围灯 | 32 | GPU 风扇 |
| 11 | 计算器 | 33 | Win 键锁 |
| 12 | 默认浏览器 | 13/14 | NumLock / ScrLock |

## 8. GPU 超频（KaronOC.dll）

```csharp
[DllImport("KaronOC.dll", CallingConvention = CallingConvention.Cdecl)]
int GetPstatesLevel0Settings(ref int grClockOffset, ref int memClockOffset);

[DllImport("KaronOC.dll", CallingConvention = CallingConvention.Cdecl)]
int ChangePstatesLevel0Settings(int grClockOffset, int memClockOffset);
```

- 范围（反编译）：核心时钟偏移 0–200 MHz
- 返回非 0 = 失败，控制中心会重试最多 3 次
- 第三方替代：直接用 NVAPI（`NvAPIWrapper.dll` 已在安装目录内，开源）

## 9. 已验证的调用代码

PowerShell（实测通过，见 `probe/wmi_probe.ps1`）：
```powershell
$inData = [byte[]]::new(32)
$inData[1] = 250          # Get
$inData[3] = 13           # CPUGPUFanSpeed
$mo  = New-Object System.Management.ManagementObject(
    "root\WMI", "MICommonInterface.InstanceName='ACPI\PNP0C14\MIFS_0'", $null)
$prm = $mo.GetMethodParameters("MiInterface")
$prm["InData"] = $inData
$out = $mo.InvokeMethod("MiInterface", $prm, $null)
$out.Properties["OutData"].Value
```

⚠️ 踩坑记录：
1. PowerShell 里 WMI 路径的反斜杠**不需要**双写（C# 源码里的 `\\` 是语言转义）
2. PS 5.1 中 WMI 数组参数必须显式 `[byte[]]` 强转，否则 PSObject 包装报错
3. InData 长度不是 32 时固件**直接拒绝**（反编译有 `inData.Length != 32` 检查，实测一致）
