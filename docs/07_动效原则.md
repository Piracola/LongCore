## 令牌（已落地，不得自造档位）

```scss
--ease-out: cubic-bezier(0.23, 1, 0.32, 1);
--ease-in-out: cubic-bezier(0.77, 0, 0.175, 1);
--ease-drawer: cubic-bezier(0.32, 0.72, 0, 1);

--dur-press: 120ms;  /* 按压 / 焦点 */
--dur-fast: 150ms;   /* 短时态变 / 模式 / 菜单 */
--dur-base: 200ms;   /* 温度语义色变 */
--dur-slow: 250ms;   /* 上限，不得再大 */
```

圆角：`sm 4 / md 8 / lg 8 / xl 8`，pill 保留。

## 硬规则

1. **读数瞬时**：温度、转速、频率、拖拽中的曲线节点 — **禁止** transition。  
2. **导航高频面**：禁止位移整页切换；禁止无限脉冲/装饰循环。  
3. **禁** `transition: all`；必须写清属性列表。  
4. **禁** hover 上浮 + 辉光；焦点环必须 `:focus-visible` 可见（`:where` 降特异度）。  
5. **reduced-motion** 全局覆盖；加载圈可豁免。  
6. **应用成功反馈**：一次性边框/状态点，不靠 toast  alone。  
7. 装饰动画（假 ECG、无限 spin）**一律删除**（09 范围）。
