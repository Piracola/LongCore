LongCore 标识 · 4 个方向对照

判定标准只有一条：16px 下还认得出来吗（任务栏 / 托盘 / Alt-Tab 的真实尺寸）。 下面每个方案都同时给出 256 / 48 / 32 / 16 px，深底与浅底各一组。 最左侧是现状对照——注意它用的是紫色 + 蓝色，正是 DESIGN.md v2 明确禁止的「紫罗兰主色」。

对照 · 现状（八臂龙鳞）

问题不在画得好不好：八个完全对称的径向臂没有方向，所以读起来是齿轮 / 星芒 / 病毒， 而不是鳞。龙鳞的关键是同向叠压（像瓦片），径向对称把这一点彻底消掉了。配色也踩了禁区。

深底

A · 鳞脊 Scale Ridge ← 推荐

三片同向叠压的鳞，由大到小向斜上收束。叠压 + 方向 = 读得出「鳞」； 缩到 16px 时三片合并成一个干净的斜向楔形，仍可辨识。保留「龙」，但不画龙。

浅底

B · 核 Core

纯几何：机加工感的环 + 45° 核心。零叙事，最「大厂」。 16px 下退化为一个带方点的圆环，辨识度最高，但完全不保留「龙」。

深底
浅底

C · 刻度核 Core + Tick

在 B 上引入仪器刻度——正好呼应 v3 计划里的签名物②「仪器刻度条」。 标识与产品最独特的功能同源。风险：三根刻线在 16px 下会糊，需要再做减一档。

深底
浅底

D · 鳞核 Scale + Core

A 与 B 的合并：一片鳞环抱核心。256px 下最有作者性， 但 16px 下鳞与核互相吃掉，是三案里小尺寸风险最高的一个。若选它，需要单独做一个小尺寸简化版。

深底

取舍口径：既然产品身份是「精密仪器」，小尺寸可辨识性优先于大尺寸表现力—— 这个图标 90% 的出场场景是 16px 的任务栏，不是商店页。 配色统一为冷青 #22d3ee（暗）/ #0891b2（亮），紫色完全移除。
