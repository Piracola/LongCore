# 已知问题清单（Known Issues）

> 版本：LongCore 0.1.0 · 2026-09 · 持续更新

## 行为限制（设计如此 / 有意取舍）

1. **浏览器直连预览显示全 0**
   通过普通浏览器访问前端页面时没有 WebView2 桥（`window.chrome.webview` 缺失），
   温度/转速/功耗等数据全部为 0。这是预期行为——完整功能必须在主窗口内使用。

2. **飞行模式（AirPlaneMode）不提供热切换**
   EC 命令 9（显卡模式）写入后必须重启生效，不能作为"模式热切换"处理。
   独显/混合切换保留在设置页（GPUDirectConnection），切换后请手动重启。

3. **"自定义"性能模式是本地逻辑态**
   自定义档（第 4 段胶囊）不写入 EC 模式命令，仅打开命令 23 的自定义功耗子状态；
   实际 SPL/SPPT 数值以 CPU 页保存的配置为准。切回标准档时自动关闭该子状态。

4. **Fn 热键只接管性能模式键（事件 15）**
   其余 Fn 复合键（亮度/触摸板/灯效等）保持固件默认行为，LongCore 不拦截。
   可在设置页整体关闭接管（`App.HotkeyEnabled`）。

5. **OSD 需要 UI 线程可用**
   Fn 切换模式的屏幕提示经 WPF Dispatcher 显示；若主窗口线程被长时间阻塞，
   提示会延迟出现。窗口最小化到托盘时 OSD 仍可正常弹出。

## 平台 / 环境相关

6. **必须管理员权限运行**
   EC 驱动加载、WMI 写入、`powercfg` 联动均需要管理员。安装器已配置
   `requireAdministrator`；若直接运行 exe 被拒，请右键"以管理员身份运行"。

7. **WMI 通道抖动**
   响应校验失败会自动重试一次（连续两次失败判定为通道异常并返回默认值）。
   休眠唤醒后首几次读取可能短暂失败，随后自愈；若持续失败请重启应用。

8. **GPU 温度来源依赖 NVAPI**
   NVIDIA 驱动不可用或初始化失败时，自动风扇控制回退用 CPU 温度驱动双风扇
   （跨散热联动），日志中会有对应告警。

9. **无噪音传感器**
   首页噪音值按风扇转速查表估算（3000 RPM≈25 dBA 标定），仅供参考。

## 版本历史修复（上游问题，本 fork 已解决）

10. **性能模式枚举错位**（上游遗留）：前端 TS 枚举顺序与后端 C# 枚举不一致，
    上游靠页面"错位命名"掩盖。0.1.0 起前后端枚举已对齐（Balance=0 / Performance=1 /
    Quiet=2 / Custom=3）。

11. **EC 高频重复写入**（上游遗留）：自动风扇控制环曾以固定 1s 周期无条件重写 EC。
    现已加入同地址同值 300ms 去重节流与写入地址白名单。

12. **崩溃后风扇状态残留**（上游遗留）：进程硬崩溃时手动风扇模式可能残留在 EC 中。
    现已加入心跳护栏，下次启动检测到过期心跳会自动恢复风扇自动模式。
