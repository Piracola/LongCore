> 截图的来源 = 提交号 + 主题 + 视口 + DPR + 工具版本。缺任一项即不可用作证据。

## 工具

`JiaoLongControl/Client/scripts/visual-shot.mjs`

- Vite dev server + `playwright-core` 驱动**系统 Edge**（`msedge.exe`）
- **mock 了整个 WebView2 bridge**（`hostObjects.bridge` 经 `addInitScript` 注入）→ 不需要真机也能渲染
- 固定视口 **1440×900**，`deviceScaleFactor: 1`
- 可强制主题（`forceTheme()`），深浅色各拍一轮
- 产出目录：`JiaoLongControl/Client/.visual-qa/`（已 gitignore，可由脚本重新生成）

运行：

```powershell
cd LongCore\JiaoLongControl\Client
node scripts\visual-shot.mjs
```
